# Arquitetura — Automation Lead Intelligence

Este projeto segue o princípio de **automação orientada a decisão**.

## Decisões arquiteturais

- Entrada desacoplada da lógica
- Padronização antes da IA
- IA responsável por classificação e resumo
- Switch substitui cadeias de IF
- Um ponto claro de ação

## Benefícios

- Redução de trabalho manual
- Critérios consistentes
- Fácil adaptação a novos canais
